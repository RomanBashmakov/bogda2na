# bogda2na — генераторы схем для бисероплетения

Кружок на схеме = одна бисерина, цифра в кружке = номер коробочки
с бисером этого цвета. Печатные схемы — HTML под A4.

## Карта проекта

| Папка | Что это |
|---|---|
| `Main_Panel/` | веб-панель: запуск всех генераторов из браузера, загрузка картинок, список готовых схем |
| `text2glitch/` | генератор «надпись → глитч-схема пояса» (`glitch.py`) |
| `painter/` | редактор схем: рисование мышью + оцифровка картинки (`digitize.py`) и печать A4 (`render.py`) |
| `client_shop/` | онлайн-конструктор «картина из бисера по вашей картинке» для клиентов: цена, заказы |
| `bead3d/` | 3D-модель оплетённой бусины + 2D-развёртка (Three.js, статичная страница) |
| `business/` | аналитика Telegram-канала (`tg/`) и локальная копия сайта 2n-beads.art (`site/`) |
| `documents/LLM/Audio/` | озвучка книг локальным Silero TTS (fb2/epub/txt → mp3) |
| `assets/` | картинки-примеры и прочие исходники |

Подробные мануалы — в README рядом с каждым модулем.

## Установка (однократно на каждой машине)

Нужен Python 3.8+. Затем из корня проекта:

- **Linux/macOS:** `bash setup.sh`
- **Windows:** `setup.cmd`

Скрипт сам подберёт работающий вариант (готовый `.venv`, системный Pillow,
новый `.venv` или `pip install --user`) и напишет, каким интерпретатором
пользоваться. Зависимости: Pillow (оцифровка картинок) и Flask (веб-панель).

## Запуск

Всё просто через веб-панель (из корня проекта):

```bash
python3 Main_Panel/app.py        # открыть http://127.0.0.1:8000
```

Вкладки: «Надпись» (text2glitch), «Картинка» (оцифровка в редактор),
«Рисовать схему» (редактор painter). Печать — открыть схему в новой
вкладке → Ctrl+P (A4, масштаб 100 %, фоновая графика вкл.).

Или напрямую из термина:

```bash
.venv/bin/python text2glitch/glitch.py -t belt_90 --text "ГЛИТЧ"
.venv/bin/python painter/digitize.py картинка.png -n 8
```

Результаты кладутся в `out/` рядом со скриптом: основной HTML + папка
`<имя>_cols<N>_colors<M>/` с одноцветными схемами (файл на коробочку).

Остальные модули:

```bash
python3 client_shop/app.py                       # http://127.0.0.1:8100
bash documents/LLM/Audio/setup.sh                # озвучка книг (см. её README)
```
