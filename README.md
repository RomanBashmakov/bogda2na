# bogda2na — генераторы схем для бисероплетения

Печатные схемы (HTML под A4): надпись → схема, этно-пояс и редактор
`picher` — картинка оцифровывается в схему, правится мышью и печатается.
Кружок на схеме = одна бисерина, цифра в кружке = номер коробочки
с бисером этого цвета.

| Скрипт | Что делает | Зависимости |
|---|---|---|
| `patterns/glitch.py` | надпись многоцветным пиксельным шрифтом → схема | только стандартная библиотека |
| `belt_rus_generator/belt_rus.py` | пояс «этно» (ромб-крест-ёлочка) | только стандартная библиотека |
| `picher/digitize.py` | картинка (jpg/png) → схема в редакторе (N цветов) | Pillow |
| `picher/render.py` | схема редактора → печатная A4-схема (+одноцветные) | только стандартная библиотека |

Подробный мануал по `glitch.py`: [`patterns/README.md`](patterns/README.md).

## Установка (однократно на каждой машине)

Нужен Python 3.8+ (`python.org/downloads`, на Windows отметить
«Add python.exe to PATH»). Затем из корня проекта:

- **Linux/macOS:** `bash setup.sh`
- **Windows:** `setup.cmd`

Скрипт сам подберёт работающий вариант, ничего не ломая в системе:

- если Pillow уже есть в найденном Python — ничего не ставит;
- иначе создаёт виртуальное окружение `.venv` и ставит зависимости из
  `requirements.txt` (внешние — Pillow и Flask; Pillow нужна только
  `picher/digitize.py`, Flask — веб-интерфейсу);
- если `.venv` создать нельзя (нет `python3-venv`) — ставит в профиль
  пользователя (`pip install --user`);
- если не выходит ничего — печатает точную команду для установки
  недостающего пакета.

Повторный запуск безвреден. Установка зависимостей требует интернет;
на последующие запуски интернет не нужен. Каким именно интерпретатором
запускать генераторы — setup напишет в конце (`.venv/bin/python` или
обычный `python3`).

## Запуск

Все команды — из корня проекта. Вариант А — если setup создал `.venv`:

```bash
# надпись → схема
.venv/bin/python patterns/glitch.py -t belt_90 --text "ГЛИТЧ"

# этно-пояс
.venv/bin/python belt_rus_generator/belt_rus.py

# картинка → схема (нужен Pillow)
.venv/bin/python img_generator/img_belt.py картинка.png -n 8
```

Вариант Б — если setup обнаружил, что Pillow уже есть в системном Python:
те же команды с обычным `python3` вместо `.venv/bin/python`.
Windows: `.venv\Scripts\python` вместо `.venv/bin/python` и `\` вместо `/`.

Короче — после активации окружения:

```bash
source .venv/bin/activate        # Windows: .venv\Scripts\activate
python img_generator/img_belt.py картинка.png -n 8
```

У каждого генератора есть шпаргалка с примерами: `python3 patterns/glitch.py help`
(то же для остальных скриптов; показывается и при запуске без аргументов).

Результат кладётся в `out/` рядом со скриптом: основной HTML + папка
`<имя>_cols<N>_colors<M>/` с одноцветными схемами (файл на каждую коробочку).

## Веб-интерфейс (запуск генераторов из браузера)

Вместо команд в терминале можно пользоваться локальной страницей:
формы всех трёх генераторов со всеми параметрами, загрузка картинок
для «картинка → схема», список готовых схем с просмотром (новая вкладка,
печать — Ctrl+P) и удалением (файл + папка одноцветных схем). Вкладка
«Рисовать схему» открывает редактор `picher` — схему можно не
генерировать, а нарисовать мышью самому (палитра-коробочки, симметрия,
раппорт с повтором до конца); схемы хранятся на сервере в
`picher/schemes/` и/или файлом JSON. Подробно: [`picher/README.md`](picher/README.md).

```bash
python3 web/app.py            # открыть http://127.0.0.1:8000
python3 web/app.py --no-browser --port 8080
```

Нужен Flask: ставится `setup.sh`/`setup.cmd` вместе с остальными
зависимостями. Если setup ничего не ставил (Pillow уже был в системном
Python, а pip в системе нет), достаточно `sudo apt install python3-flask`
(Linux) или `py -m pip install flask` (Windows). Сервер слушает только
127.0.0.1 — наружу не виден. Загруженные картинки хранятся в
`web/uploads/` (в git не попадают).

## Озвучка книг (локальный Silero TTS)

FB2/EPUB/TXT → папка mp3 по главам, всё локально (без облака),
на GPU, если есть:

```bash
bash tts/setup.sh                                # разово, ~3 ГБ качается
tts/.venv/bin/python tts/book2audio.py --demo    # послушать 5 голосов
tts/.venv/bin/python tts/book2audio.py help      # шпаргалка с примерами
tts/.venv/bin/python tts/book2audio.py книга.fb2 # → tts/out/<книга>/*.mp3
```

Подробно: [`tts/README.md`](tts/README.md).
