
Вот текстовое описание техники оплетения бусины 14–15 мм бисером Delica, составленное на основе мастер-класса.

Материалы
Для работы потребуется: бусина диаметром 14–15 мм, бисер Delica 11.0, бисер Miyuki или Toho 15.0, игла для бисероплетения, нить, штифт.

Техника оплетения
Плетение начинается с набора четырёх бисерин Delica, которые замыкаются в кольцо. В следующем ряду через каждую Delica набирается по одной бисерине размера 15.0. В конце каждого ряда игла всегда выводится через первую бисерину только что проплетённого ряда — это необходимо для подъёма на следующий уровень.

Далее набираются по две Delica за раз, и они проплетаются через каждую пятнашку предыдущего ряда. Игла выводится через первую бисерину Delica последнего ряда. Затем снова набирается по одной бисерине 15.0 через каждую Delica. В следующем ряду — по две пятнашки за раз, а в конце ряда игла выводится через обе первые пятнашки этого ряда.

После этого набирается по одной Delica через каждые две пятнашки. На этом этапе оплётка начинает приобретать форму «чашечки». В неё вставляется бусина, предварительно надетtая на штифт. Чашечку нужно разгладить, чтобы бисер не топорщился, или слегка подтянуть нить, чтобы она плотно легла на бусину.

В следующем ряду снова набирается по две пятнашки через каждую Delica, игла выводится через первую пятнашку. Затем — по одной пятнашке через каждую пятнашку предыдущего ряда. После этого — по одной Delica через каждую пятнашку. Бусину со штифтом следует держать пальцами, плотно прижимая чашечку к бусине.

Далее идёт ряд по одной Delica, и так провязывается 10–11 рядов в зависимости от размера бусины. Затем выполняются зеркальные убавки: по одной пятнашке через каждую Delica, затем по одной пятнашке через каждую пятнашку. В следующем ряду — убавка: по одной Delica через две пятнашки. В конце каждого ряда игла по-прежнему выводится через первую бисерину этого ряда.

Затем набирается по две пятнашки через каждую Delica, игла выводится через первые две пятнашки. Далее — по одной пятнашке через каждые две пятнашки предыдущего ряда. После — по одной Delica через каждую пятнашку. В следующем ряду снова убавка: по одной пятнашке через две Delica. Завершающий ряд — по одной Delica, всего четыре бисерины. Нитка проходит по кругу несколько рядов вниз и обрезается.

Примечания
Чтобы оплётка не топорщилась, можно начать и закончить плетение не четырьмя бисеринами Delica, а четырьмя бисеринами размера 15.0. Размер оплётки регулируется количеством средних рядов Delica. Если взять Delica и бисер 15.0 одного цвета, получится однотонная бусина. Также можно комбинировать цвета.


1. Материалы
На фото разложены: крупная бусина 14–15 мм, бисер Delica 11/0, мелкий бисер 15/0, игла, нить, штифт. Видно, что Delica — это ровные цилиндрические бисерины, а 15/0 — маленькие круглые. Бусина лежит отдельно, штифт вставлен в неё или лежит рядом.

2. Начало: кольцо из 4 Delica
На фото игла с нитью проходит через 4 бисерины Delica, замкнутые в кольцо. Кольцо лежит плоско, как маленький квадрат. Нить затянута, но не слишком туго. Игла выходит из одной из Delica. Это основа будущей оплётки.

3. Первый ряд из 15/0
Через каждую Delica набрано по одной бисерине 15/0. На фото видно, как между крупными Delica появились мелкие бисерины. Кольцо стало больше, чередование размеров заметно. Игла выведена через первую 15/0 этого ряда — это подъём на следующий уровень.

4. Ряд из пар Delica
Теперь через каждую 15/0 набрано по две Delica. На фото видно, как образуются «лепестки» или «зубчики»: крупные бисерины идут парами. Оплётка начинает расширяться и приобретать объём. Игла выходит через первую Delica последней пары.

5. Ряд из 15/0 между Delica
Через каждую Delica добавлено по одной 15/0. На фото — снова чередование: Delica, мелкая бисерина, Delica, мелкая. Круг растёт, форма становится более выпуклой. Игла выходит из первой 15/0 ряда.

6. Ряд из пар 15/0
Через каждую Delica (или через нужные бисерины) набрано по две 15/0. На фото видно, как мелкий бисер ложится парами, образуя плотное кольцо. В конце ряда игла выводится сразу через обе первые 15/0 — это видно по тому, что нить проходит через две маленькие бисерины подряд.

7. Ряд Delica через пары 15/0
Через каждые две 15/0 проплетается одна Delica. На фото оплётка уже похожа на чашечку: крупные Delica образуют внешний край, мелкие — внутренний. Чашечка слегка загибается вверх. Игла выходит из первой Delica.

8. Вставка бусины
Самый важный кадр: в получившуюся чашечку вставляется бусина 14–15 мм, надетaя на штифт. На фото видно, как пальцы придерживают бусину, а оплётка облегает её снизу. Чашечку разглаживают, чтобы бисер не топорщился. Если нужно, нить слегка подтягивают — оплётка садится плотно. Штифт выходит из отверстия бусины вверх.

9. Ряд из пар 15/0 вокруг бусины
Теперь по краю чашечки снова набирается по две 15/0 через каждую Delica. На фото видно, как мелкий бисер идёт по верхнему краю оплётки, прижимаясь к бусине. Игла выходит через первую 15/0. Бусина пока видна сверху, но уже начинает закрываться.

10. Ряд из одиночных 15/0
Через каждую 15/0 предыдущего ряда проплетается по одной 15/0. На фото мелкий бисер ложится плотнее, верхний край оплётки стягивается. Бусина обхватывается всё сильнее.

11. Ряд Delica через 15/0
Через каждую 15/0 набирается Delica. На фото видно, как крупные бисерины начинают закрывать верх бусины. Оплётка становится похожа на мешочек. Игла выходит из первой Delica.

12. Основные ряды Delica
Далее идут ряды только Delica — примерно 10–11 рядов. На фото видно, как оплётка поднимается по бусине вверх, плотно облегая её. Бусина постепенно скрывается внутри. Игла каждый раз выводится через первую бисерину ряда. Нить подтягивается после каждого ряда, чтобы не было просветов.

13. Зеркальные убавки
Начинается сужение. Сначала ряд: по одной 15/0 через каждую Delica. Затем ряд: по одной 15/0 через каждую 15/0. На фото видно, как верх оплётки стягивается, отверстие уменьшается. Бусина уже почти полностью закрыта.

14. Убавка Delica
Следующий ряд: по одной Delica через две 15/0. На фото — крупные бисерины идут реже, образуя маленькое кольцо. Отверстие становится совсем небольшим.

15. Пары 15/0
Снова набирается по две 15/0 через каждую Delica. Игла выводится через первые две 15/0. На фото видно, как мелкий бисер закрывает верх, стягивая его.

16. Одиночные 15/0 через пары
Через каждые две 15/0 проплетается по одной 15/0. На фото верхнее отверстие становится крошечным. Бусина полностью внутри.

17. Ряд Delica
Через каждую 15/0 — Delica. На фото остается маленькое кольцо из крупных бисерин. Игла выходит из первой Delica.

18. Финальная убавка
Ряд: по одной 15/0 через две Delica. На фото — последние мелкие бисерины стягивают верх. Остаётся отверстие в 4 бисерины.

19. Завершение
Последний ряд: по одной Delica, всего 4 бисерины. На фото видно, как четыре Delica замыкают верх. Нить проходит по кругу, затем спускается вниз через несколько рядов, закрепляется и обрезается. Штифт торчит наружу.

20. Готовая бусина
На финальном фото — оплетённая бусина. Видно, что оплётка плотная, бисер лежит ровно, без бугров. Бусина внутри не просвечивает. Штифт готов для крепления.

Главное, что видно на фото:

чашечка формируется постепенно, снизу вверх;

бусина вставляется до того, как верх начнёт закрываться;

каждый ряд заканчивается подъёмом через первую бисерину;

нить подтягивается после каждого ряда;

убавки идут зеркально прибавкам;

верх стягивается до 4 Delica.

Ниже — максимально подробное описание одной оплетённой бусины 14–15 мм, выполненной по тому же принципу, что и в мастер-классе: двумя размерами бисера (Delica и 15/0), слоями-кольцами от нижнего полюса к верхнему, со сдвигом каждого слоя на полбисерины относительно предыдущего.

1. Общая геометрия
Готовая оплётка — это плотный чехол сферической формы, надетый на бусину. Внутри — бусина 14–15 мм, снаружи — сетка из бисера. Слои идут параллельными кольцами от нижнего полюса (глухого, противоположного отверстию) к верхнему полюсу (там, где отверстие и штифт). Каждый слой — это кольцо бисера. В нижней полусфере кольца расширяются, в экваториальной зоне идут ровно, в верхней полусфере сужаются. Все слои смещены друг относительно друга на полбисерины: каждая бисерина нового слоя ложится в промежуток между двумя бисеринами предыдущего слоя. Это создаёт кирпичную/пейотовую структуру без вертикальных швов.

В работе чередуются два типа бисера:

Delica — крупный цилиндрический бисер (основной).

15/0 — мелкий круглый бисер (акцентный, заполняет промежутки и формирует скругления).

Нижний полюс начинается с 4 Delica. Верхний полюс заканчивается 4 Delica вокруг отверстия для штифта. На экваторе — 16 Delica (для данной схемы). Между полюсами и экватором идут промежуточные слои, где количество бисера то увеличивается, то уменьшается, создавая плавный изгиб сферы.

3. Внешний вид по зонам
Нижний полюс (слои 0–2)
В центре — маленький крест из 4 Delica. Между ними выглядывают 4 бисерины 15/0, как точки. Над ними — 8 Delica, образующих восьмиконечную звезду. Центр глухой, без отверстия. Оплётка здесь плотно прилегает к нижней точке бусины.

Нижняя полусфера (слои 3–5)
Идёт расширение. 15/0 образуют концентрические кольца, Delica — радиальные лучи. Постепенно появляется объём, оплётка принимает форму чашечки. В этот момент в неё вставляется бусина. Чашечку разглаживают пальцами, чтобы бисер не топорщился, и слегка подтягивают нить.

Экватор (слои 8–19)
Самый широкий участок. Здесь только Delica — 16 штук в кольце. Они образуют вертикальные столбики, сдвинутые относительно друг друга на полбисерины. Поверхность гладкая, как чешуя. Высота экватора — 11 рядов, что соответствует диаметру бусины 14–15 мм. Именно этот участок даёт основную плотность и форму.

Верхняя полусфера (слои 20–27)
Зеркальное сужение. Снова появляются 15/0, которые стягивают верх. Верхний полюс — 4 Delica вокруг отверстия. Штифт выходит из центра. Оплётка плотно обхватывает бусину, не просвечивает.

4. Технические детали
Подъём: в конце каждого ряда игла выводится через первую бисерину только что проплетённого ряда. Это нужно для перехода на следующий уровень.

Натяжение: после каждого ряда нить подтягивается. Если не подтягивать, сдвиг на полбисерины не будет держаться, и оплётка получится рыхлой.

Вставка бусины: бусина надевается на штифт и вставляется в чашечку после слоя 5. Дальше её придерживают пальцами, прижимая оплётку, чтобы она не соскочила.

Закрытие верха: верхние слои идут вокруг штифта. Последние 4 Delica образуют кольцо вокруг отверстия.

Если оплётка топорщится: можно начать не с 4 Delica, а с 4 бисерин 15/0 — тогда нижний полюс будет плотнее. Или слегка подтянуть нить в проблемных местах.

5. Вариации
Цвет: Delica — основной цвет, 15/0 — контрастный акцент. Тогда нижний полюс выглядит как звезда с точками, экватор — однотонный, верх — снова с акцентом. Можно делать градиент, меняя цвет Delica каждые 2–3 ряда.

Размер: для бусины 14 мм хватает 16 Delica на экваторе и 11 рядов ровного участка. Для 15 мм можно добавить 1–2 ряда или взять 18 Delica. Для 12 мм — 14 Delica и 9 рядов.

Если используется Delica 11/0: для бусины 14–15 мм её потребуется больше — около 28–30 штук на экваторе. Схему нужно масштабировать: увеличить количество слоёв расширения и ровного участка пропорционально.

В итоге получается плотная, ровная оплётка, которая повторяет форму бусины. Слои идут от нижнего полюса к верхнему, каждый слой сдвинут на полбисерины, а чередование Delica и 15/0 создаёт плавные скругления на полюсах и гладкий цилиндр на экваторе.
