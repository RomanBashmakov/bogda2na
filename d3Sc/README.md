# d3Sc — оплетённая бусина из бисера: 3D-модель + 2D-развёртка, интерактивно

Статичная страница, сервер и интернет не нужны: Three.js лежит рядом.
Модель воспроизводит технику оплетения бусины 14–15 мм бисером Delica 11/0
и 15/0 (описание техники — в `site.txt`).

## Запуск

Открыть двойным кликом `d3Sc/index.html` (или в браузере: Файл → Открыть).

## Модель плетения (по site.txt)

Ряды снизу вверх: кольцо из 4 Delica → 4×15/0 → 8 Delica (парами) →
8×15/0 → 16×15/0 (парами) → 8 Delica → 16×15/0 → 16×15/0 → 16 Delica →
**средние ряды Delica (настраиваются, по умолчанию 11)** → зеркальные
убавки: 16×15/0 → 16×15/0 → 8 Delica → 16×15/0 → 8×15/0 → 8 Delica →
4×15/0 → 4 Delica.

## Физическая укладка (симуляция)

Позиции бисерин считаются релаксацией, а не формулами:

- связи «нити»: каждая бисерина пружинно связана с двумя ближайшими
  бисеринами соседнего ряда (пейот-связи) и с соседями по кольцу —
  целевая дистанция = касание торцами;
- жёсткое **непроникновение**: каждая бисерина — капсула (цилиндр из
  двух сфер), пересечения выталкиваются;
- внутренняя бусина — упор: провалиться внутрь нельзя;
- масштаб держится нормировкой среднего радиуса.

Итог: соседние по нити бисерины касаются, наложения ≤ ~0.2 мм
(погрешность релаксации), вписанная бусина для паттерна по умолчанию
получается ⌀ ~15 мм — как в мастер-классе.

- Калибры (`BEAD` в `app.js`): Delica — 2.8×2.6 мм, 15/0 — 1.7×1.9 мм
  (подобраны под паттерн 16 Delica на экваторе; можно править).
- «Бусина, мм» — стартовый/минимальный диаметр внутренней бусины;
  итоговый размер определяет паттерн и калибры (в статусе видно оба).
- Генерация занимает 1–3 секунды (симуляция).


## Параметры

- **Бусина, мм** — стартовый/минимальный диаметр внутренней бусины
  (итог см. в статусе).
- **Средних рядов Delica** — сколько рядов по «пояску» (регулирует размер
  оплётки, как в мастер-классе).

## Интерактив

- Слева 3D: вращение мышью, зум колесом, клик по бисерине — выбрать и
  покрасить текущим цветом/размером. Каркас — внутренняя бусина.
- Справа 2D-развёртка в реальных мм-пропорциях: клик — то же самое.
- Правки в любой панели мгновенно отражаются в другой; выбранная бисерина
  подсвечена в обоих видах.
- Цвета с номерами коробочек (кружок = бисерина, цифра = коробочка),
  палитра расширяемая; любой бисерине можно вручную сменить размер
  (Delica ↔ 15/0) галочкой «мелкий».
- Сохранение/загрузка JSON, печать развёртки A4 (пунктир = 15/0),
  снимок 3D в PNG.
