# d3Sc — оплетённая бусина из бисера: 3D-модель + 2D-развёртка, интерактивно

Статичная страница, сервер и интернет не нужны: Three.js лежит рядом.
Модель воспроизводит технику оплетения бусины 14–15 мм бисером Delica 11/0
и 15/0 (описание техники — в `site.txt`).

## Запуск

Открыть двойным кликом `d3Sc/index.html` (или в браузере: Файл → Открыть).

## Модель плетения (по site.txt)

Ряды снизу вверх: кольцо из 4 Delica → 4×15/0 → 8 Delica (парами) →
8×15/0 → 16×15/0 (парами) → 8 Delica → 16×15/0 → 16×15/0 → 16 Delica →
**средние ряды Delica (настраиваются, по умолчанию 11)** → зеркальные
убавки: 16×15/0 → 16×15/0 → 8 Delica → 16×15/0 → 8×15/0 → 8 Delica →
4×15/0 → 4 Delica.

## Физическая укладка (PBD-решатель)

Позиции бисерин считает проекционный решатель (Position Based Dynamics),
а не формулы. Приоритеты ограничений:

- **виртуальная сфера обжатия** — мягкая: её радиус = максимум из
  введённого старта и минимальной оценки по площади плетения (площадь
  бисерин × 0.8 с учётом частичного утапливания рядов). Размер задаёт
  само плетение, сфера лишь округляет форму; жёсткого натягивания
  на заданную бусину нет;
- **непроникновение** — жёстко и для ВСЕХ пар, включая соседей по нити
  (кольцо и пейот): иначе сжатые кольца сминаются внахлёст («утопленные»
  бисерины). Нитевым парам дан малый допуск утапливания 0.25 мм — как
  лёгкое вложение рядов в реальном плетении. Бисерина = капсула,
  ориентация обновляется каждый шаг;
- **нить** — слабо: внутри кольца наезжать нельзя (правится жёстко), а
  растянутые связи подтягиваются слабо; пейот — только подтяжка с люфтом
  0.1 мм (нить слегка растяжима: в тесных местах ход отдаётся коллизиям).
  Где паттерну тесно, там остаётся видимый зазор — «расслабленное» место;
  где помещается — бисерины стоят касанием («напряжение»).

Размер задаёт само плетение: нормировки среднего радиуса нет. Каркас в 3D
рисуется по фактической вписанной бусине; в статусе — итоговый размер
модели (⌀ ширина × высота), вписанная бусина и максимальный зазор нити.

- Генерация — анимированная: видно, как оплётка обжимается сферой
  (кадр = 12 итераций решателя). Правки размера бисерин и загрузка JSON —
  мгновенный пересчёт.
- Калибры (`BEAD` в `app.js`): Delica — 2.8×2.6 мм, 15/0 — 1.7×1.9 мм
  (подобраны под паттерн 16 Delica на экваторе; можно править).
- «Бусина, мм» — старт обжатия (нижний ориентир); итоговый размер
  определяется плетением и виден в статусе.

## Подсветка натяжения

Галочка «натяжение» внизу: красный — нить натянута (бисерины касанием),
зелёный — расслаблена (зазор до 10% радиуса бусины). Действует в 3D и в
2D-развёртке, на печать не влияет. По цвету видно, где паттерн «напрягается»,
а где остаётся запас.


## Параметры

- **Бусина, мм** — стартовый/минимальный диаметр внутренней бусины
  (итог см. в статусе).
- **Средних рядов Delica** — сколько рядов по «пояску» (регулирует размер
  оплётки, как в мастер-классе).

## Интерактив

- Слева 3D: вращение мышью, зум колесом, клик по бисерине — выбрать и
  покрасить текущим цветом/размером. Каркас — внутренняя бусина.
- Справа 2D-развёртка в реальных мм-пропорциях: клик — то же самое.
- Правки в любой панели мгновенно отражаются в другой; выбранная бисерина
  подсвечена в обоих видах.
- Цвета с номерами коробочек (кружок = бисерина, цифра = коробочка),
  палитра расширяемая; любой бисерине можно вручную сменить размер
  (Delica ↔ 15/0) галочкой «мелкий».
- Сохранение/загрузка JSON, печать развёртки A4 (пунктир = 15/0),
  снимок 3D в PNG.
