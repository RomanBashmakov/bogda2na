# Инструкция: генератор схем бисерных поясов (глитч-надписи)

`glitch_belt.py` превращает надпись в глитч-стиле в печатную схему пояса из
бисера: лист A4 с кружочками. Каждый кружок = одна бисерина. Заливка кружка —
цвет, цифра внутри — **номер коробочки** с бисером этого цвета: достал
бисерину из коробочки №N → положил на кружок №N.

Скрипт на чистом Python 3.8+ — ничего устанавливать не нужно.

## 0. Что понадобится

- компьютер с Python 3.8+ (проверка: `python3 --version`);
- браузер (Chrome / Firefox / Edge) и принтер;
- файлы проекта: `patterns/glitch_belt.py` и `patterns/palette.json`.

## 1. Запуск

Откройте терминал в папке проекта и выполните:

```bash
python3 patterns/glitch_belt.py --text "ГЛИТЧ" --length-cm 90 --width-cm 4
```

Результат — файл `patterns/out/ГЛИТЧ.html`. Удобно сразу задать имя файла:

```bash
python3 patterns/glitch_belt.py --text "ГЛИТЧ" --length-cm 90 --width-cm 4 \
    --seed 42 --title "Пояс №1" --out patterns/out/poyas1.html
```

Скрипт печатает в консоль итог: фактический размер сетки, поля текста и
сколько бисерин каждого номера подготовить. Если появились строки с «⚠» —
прочитайте их (это подсказки, а не ошибки).

## 2. Подгонка под оснастку (важно!)

Оснастка — лист/доска с отверстиями под бисерины. Чтобы кружки на бумаге
совпали с отверстиями, измерьте на оснастке:

- **шаг** — расстояние между центрами соседних отверстий → `--pitch-mm`
  (по умолчанию 2.5 мм);
- **диаметр кружка** на бумаге = шаг − `--circle-gap` (зазор, по умолчанию
  0.4 мм). Кружок должен быть чуть меньше отверстия — тогда он виден вокруг
  бисерины и отверстие не «съедает» цифру.

Ориентиры по бисеру: чешский 10/0 ≈ 2.3 мм, 9/0 ≈ 2.6 мм, 8/0 ≈ 3.1 мм.

Пример: отверстия с шагом 3 мм, кружок нужен ⌀2.4 мм →
`--pitch-mm 3 --circle-gap 0.6`.

**Размер изделия**: `--length-cm` (длина) и `--width-cm` (ширина). Сетка =
размер ÷ шаг, поэтому фактический размер кратен шагу — точные цифры скрипт
пишет в консоль и в шапку схемы.

## 3. Надпись и глитч-стиль

| Параметр | Что делает | Пример |
|---|---|---|
| `--text` | надпись: латиница, кириллица, цифры, знаки `.,!?-+/#@:'*_()` | `--text "ЭХО 2026"` |
| `--glitch` | сила глитча: `0` чистый текст, `0.3` лёгкий, `0.5` обычный, `0.8` агрессивный | `--glitch 0.7` |
| `--seed` | вариант случайных эффектов: не понравилось — смените число, понравилось — запишите | `--seed 7` |
| `--tracking` | расстояние между буквами, колонок | `--tracking 2` |
| `--rgb-shift` | разброс цветных дубляжей текста, колонок (0 = авто) | `--rgb-shift 3` |
| `--mirror` | зеркальная схема — если техника плетения читает схему наоборот | |

Текст всегда центрируется; трекинг автоматически подгоняется так, чтобы
поля слева/справа были равными.

## 4. Печать

1. Откройте HTML-файл в браузере.
2. `Ctrl+P` (Mac: `⌘P`).
3. Настройки: **A4 · портрет · масштаб 100 % («Реальный размер»)**.
4. Включите **«Фоновая графика»** — иначе кружки напечатаются без заливки.
5. Распечатайте и **проверьте калибровочную линейку** на первом листе:
   линия должна быть ровно 100 мм. Не совпадает — принтер масштабирует
   лист, вернитесь к настройке масштаба и повторите печать.

## 5. Как читать схему

- Длинный пояс разрезан на **сегменты** по ширине листа. В заголовке
  сегмента — диапазон колонок («колонки 1–74»), на линейке сверху — номера
  колонок каждые 10. Сегменты склеиваются/стыкуются по линиям отреза.
- **Ряды** пронумерованы слева (1 — верхний ряд пояса).
- Кружок с цифрой N → бисерина из коробочки №N. Заливка цветом помогает
  сразу видеть рисунок и не ошибаться.
- **Легенда** на первом листе: номер → образец цвета → название → сколько
  бисерин понадобится.
- Последние страницы — **раскладка по рядам**: запись «1×12 2×3» означает
  «12 бисерин №1 подряд, затем 3 бисерины №2». По ней удобно плести, не
  вглядываясь в мелкие кружки.

## 6. Палитра = ваши коробочки

Файл `patterns/palette.json`. Порядок цветов в списке = номера коробочек
(1-й в списке = коробочка №1 и т.д.). Можно менять `"hex"` (цвет) и
`"name"` (название) под свои бисерины; порядок элементов и роли
(`bg`, `main`, `fringe_left`, `fringe_right`, `noise_bright`, `noise_dim`)
оставляйте как есть. Свой файл палитры: `--palette мой_набор.json`.

## 7. Частые проблемы

| Симптом | Решение |
|---|---|
| «Надпись не влезает в сетку» | увеличьте `--length-cm`, уменьшите `--tracking` или сократите текст |
| «поля … НЕ равные» | при этой ширине равные поля невозможны при целом трекинге: чуть измените `--length-cm` (изменится число колонок) или `--tracking` |
| Кружки напечатались без заливки | в диалоге печати включите «Фоновая графика» |
| Линейка не 100 мм | масштаб печати не 100 % — исправьте в диалоге печати и перепечатайте |
| Цифры в кружках мелкие | так задаёт шаг сетки; вариант: `--no-numbers` — только цвета, без цифр |
| Нужен чистый текст без глитча | `--glitch 0` |
| Другой вариант глитча | меняйте `--seed` и `--glitch`, пока не понравится |

## 8. Все параметры

| Параметр | По умолч. | Описание |
|---|---|---|
| `--text` | — (обязателен) | надпись (нижний регистр → верхний) |
| `--length-cm` | 90 | длина изделия, см |
| `--width-cm` | 4 | ширина изделия, см |
| `--pitch-mm` | 2.5 | шаг сетки, мм (межцентровое расстояние) |
| `--circle-gap` | 0.4 | зазор между кружками, мм (диаметр = шаг − зазор) |
| `--glitch` | 0.5 | интенсивность глитча 0…1 (0 = чистый текст) |
| `--seed` | 42 | зерно генератора (воспроизводимость схемы) |
| `--tracking` | 1 | промежуток между буквами, колонок |
| `--no-symmetrize` | — | не подгонять трекинг для равных полей |
| `--rgb-shift` | 0 (авто) | сдвиг цветных дубляжей текста, колонок |
| `--mirror` | — | зеркальная схема (для техник с обратным чтением) |
| `--no-numbers` | — | печатать кружки без номеров |
| `--no-rowlist` | — | без раскладки по рядам |
| `--palette` | palette.json | файл палитры |
| `--title` | текст | заголовок схемы |
| `--out` | `out/<имя>.html` | выходной HTML-файл |

Готовые примеры схем лежат в `patterns/out/`.
