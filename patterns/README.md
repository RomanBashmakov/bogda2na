# Инструкция: генератор схем бисерных поясов (многоцветный шрифт)

`glitch.py` превращает надпись в печатную схему пояса из бисера: лист
A4 с кружочками. Каждый кружок = одна бисерина. Буквы рисуются многоцветным
пиксельным шрифтом из `type.txt`: у каждого пикселя свой цвет
(слева пурпурный/жёлтый, в середине белый, справа голубой/синий) — цветной
«шлейф» уже зашит в сами буквы. Заливка кружка — цвет, цифра внутри —
**номер коробочки** с бисером этого цвета: достал бисерину из коробочки
№N → положил на кружок №N.

Скрипт на чистом Python 3.8+ — ничего устанавливать не нужно.

## 0. Что понадобится

- компьютер с Python 3.8+ (проверка: `python3 --version`);
- браузер (Chrome / Firefox / Edge) и принтер;
- файлы рядом со скриптом: `glitch.py`, `type.txt` (шрифт),
  `config.json` (пресеты: размеры полотна, кружочки, цвета).

## 1. Запуск

Откройте терминал в папке со скриптом и выполните:

```bash
python3 glitch.py -t belt_90 --text "ГЛИТЧ"
```

`-t` — пресет из `config.json` (размеры полотна, шаг и диаметр
кружочков, цвета). Заготовки: `belt_90`, `bracelet_19`, `bracelet_15` —
правьте и добавляйте свои прямо в файле. Результат — файл
`out/ГЛИТЧ.html`. Удобно сразу задать имя файла:

```bash
python3 glitch.py -t belt_90 --text "ГЛИТЧ" \
    --seed 42 --title "Пояс №1" --out out/poyas1.html
```

Любое поле пресета можно переопределить флагом:

```bash
python3 glitch.py -t bracelet_19 --rows 12 --text "ЭХО"
```

Свой файл конфига — `-c мой_конфиг.json` (по умолчанию `config.json`
рядом со скриптом).

Шпаргалка с примерами и списком пресетов: `python3 glitch.py
help` — она же показывается при запуске без аргументов.

Скрипт печатает в консоль итог: фактический размер сетки, поля текста и
сколько бисерин каждого номера подготовить. Если появились строки с «⚠» —
прочитайте их (это подсказки, а не ошибки).

## 2. Подгонка под оснастку (важно!)

Оснастка — лист/доска с отверстиями под бисерины. Чтобы кружки на бумаге
совпали с отверстиями, измерьте на оснастке:

- **шаг** — расстояние между центрами соседних отверстий → поле
  `pitch_mm` в пресете (или флаг `--pitch-mm`);
- **диаметр кружка** на бумаге → поле `circle_d_mm` (или флаг
  `--circle-d-mm`). Кружок должен быть чуть меньше отверстия — тогда он
  виден вокруг бисерины и отверстие не «съедает» цифру.

Ориентиры по бисеру: чешский 10/0 ≈ 2.3 мм, 9/0 ≈ 2.6 мм, 8/0 ≈ 3.1 мм.

Пример: отверстия с шагом 3 мм, кружок нужен ⌀2.4 мм → пропишите в
пресете `"pitch_mm": 3, "circle_d_mm": 2.4` или добавьте флаги
`--pitch-mm 3 --circle-d-mm 2.4`.

**Размер изделия**: количество клеток — `--cols` (длина) и `--rows`
(ширина) либо поля `cols`/`rows` в пресете. Физический размер =
клетки × шаг; точные цифры скрипт пишет в консоль и в шапку схемы.

## 3. Надпись и шрифт

| Параметр | Что делает | Пример |
|---|---|---|
| `--text` | надпись: латиница, кириллица, цифры, пробел (строчные → ЗАГЛАВНЫЕ) | `--text "ЭХО 2026"` |
| `--tracking` | расстояние между буквами, колонок | `--tracking 2` |
| `--mirror` | зеркальная схема — если техника плетения читает схему наоборот | |
| `--seed` | вариант случайных искажений: не понравилось — смените число | `--seed 7` |
| `--font` | свой файл шрифта вместо `type.txt` | `--font мой.txt` |

Текст всегда центрируется; трекинг автоматически подгоняется так, чтобы
поля слева/справа были равными.

Шрифт — многоцветный пиксельный 7×6, живёт в `type.txt`:

- глиф = строка-метка + 6 строк по 7 цифр `0-5`; `0` — фон (пусто),
  `1-5` — цвета, совпадающие с номерами коробочек;
- «шлейф» зашит в буквы: слева пурпурный (1) и жёлтый (2), в середине
  белый (3), справа голубой (4) и синий (5);
- буквы правятся прямо в файле — скрипт перечитывает его при каждом
  запуске; метка `_` = пробел; знаков препинания и строчных нет.

Искажения (глитч) включаются флагами, сила — `--glitch 0…1`:

| Флаг | Эффект |
|---|---|
| `--dropout` | «выпадения» случайных пикселей текста в фон |
| `--slices` | горизонтальные полосы текста сдвигаются влево/вправо |
| `--blackout` | прямоугольные куски надписи целиком пропадают |

## 4. Печать

1. Откройте HTML-файл в браузере.
2. `Ctrl+P` (Mac: `⌘P`).
3. Настройки: **A4 · портрет · масштаб 100 % («Реальный размер»)**.
4. Поля печати — любые до ~13 мм: сегменты спроектированы с запасом
   (ширина ≤ 181 мм) и по краю листа не обрежутся.
5. Включите **«Фоновая графика»** — иначе кружки напечатаются без заливки.
6. Распечатайте и **проверьте калибровочную линейку** на первом листе:
   линия должна быть ровно 100 мм. Не совпадает — принтер масштабирует
   лист, вернитесь к настройке масштаба и повторите печать.

## 5. Как читать схему

- Длинный пояс разрезан на **сегменты** по ширине листа. В заголовке
  сегмента — диапазон колонок («колонки 1–74»), на линейке сверху — номера
  колонок каждые 10. Сегменты склеиваются/стыкуются по линиям отреза.
- **Ряды** пронумерованы слева (1 — верхний ряд пояса).
- Кружок с цифрой N → бисерина из коробочки №N. Заливка цветом помогает
  сразу видеть рисунок и не ошибаться.
- **Легенда** на первом листе: номер → образец цвета → название → сколько
  бисерин понадобится.

## 6. Конфиг = пресеты и коробочки

Файл `config.json`, пресет выбирается флагом `-t` (напр.,
`-t bracelet_19`). Поля пресета:

| Поле | Что задаёт |
|---|---|
| `cols`, `rows` | размер полотна в клетках: длина-колонки и ширина-ряды |
| `pitch_mm` | шаг — расстояние между центрами кружочков, мм |
| `circle_d_mm` | диаметр кружочка, мм |
| `font` | файл шрифта (отдельный, правится руками; обычно `type.txt`) |
| `colors` | 6 цветов — цифры шрифта 0-5 = номера коробочек |

`colors`: коробочка №0 — чёрный бисер для фона и т.д.; правьте `"hex"`
и `"name"` под свои бисерины, количество — ровно 6. Флаги командной
строки переопределяют поля пресета; свой конфиг — `-c мой_конфиг.json`.
Ключи конфига, начинающиеся с `_`, — комментарии.

## 7. Частые проблемы

| Симптом | Решение |
|---|---|
| «Надпись не влезает в сетку» | увеличьте `--cols`, уменьшите `--tracking` или сократите текст |
| «поля … НЕ равные» | при этой ширине равные поля невозможны при целом трекинге: чуть измените `--cols` (на 1-2 клетки) или `--tracking` |
| «В шрифте нет символов: …» | глифа нет в `type.txt`: добавьте его (метка + 6 строк по 7 цифр 0-5) или уберите символ из надписи |
| Кружки напечатались без заливки | в диалоге печати включите «Фоновая графика» |
| Линейка не 100 мм | масштаб печати не 100 % — исправьте в диалоге печати и перепечатайте |
| Цифры в кружках мелкие | так задаёт шаг сетки; вариант: `--no-numbers` — только цвета, без цифр |
| Не нужны искажения | просто не включайте флаги `--dropout` / `--slices` / `--blackout` — чистый текст получается и без них |
| Другой вариант искажений | сила — `--glitch`, вариант задаёт `--seed` |

## 8. Все параметры

| Параметр | По умолч. | Описание |
|---|---|---|
| `-c`, `--config` | config.json | файл конфига с пресетами (JSON) |
| `-t`, `--preset` | — | имя пресета из конфига, напр. `bracelet_19` |
| `--text` | — (обязателен) | надпись (строчные → ЗАГЛАВНЫЕ; знаков в шрифте нет) |
| `--cols` | пресет или 360 | длина изделия в клетках-колонках |
| `--rows` | пресет или 16 | ширина изделия в рядах |
| `--pitch-mm` | пресет или 2.5 | шаг — расстояние между центрами кружочков, мм |
| `--circle-d-mm` | пресет или шаг − 0.4 | диаметр кружочка, мм |
| `--glitch` | 0.5 | сила искажений `--dropout/--slices/--blackout` (на чистый текст не влияет) |
| `--dropout` | — | «выпадения» пикселей (по умолчанию выкл.) |
| `--slices` | — | сдвиг горизонтальных срезов (по умолчанию выкл.) |
| `--blackout` | — | блэкаут-блоки (по умолчанию выкл.) |
| `--seed` | 42 | зерно генератора (воспроизводимость схемы) |
| `--tracking` | 1 | промежуток между буквами, колонок |
| `--font` | пресет или type.txt | файл шрифта (глифы 7×6, цифры цветов) |
| `--no-symmetrize` | — | не подгонять трекинг для равных полей |
| `--mirror` | — | зеркальная схема (для техник с обратным чтением) |
| `--no-numbers` | — | печатать кружки без номеров |
| `--palette` | — | убрано: цвета теперь в пресетах конфига |
| `--title` | текст | заголовок схемы |
| `--out` | `out/<имя>.html` | выходной HTML-файл |

Готовые примеры схем лежат в `out/`.
