# tts — озвучка книг локальным ИИ (fb2/epub/txt → mp3 по главам)

Голос — Silero TTS (русские голоса, модель v4_ru). Всё работает локально,
облако не используется. GPU (NVIDIA) ускоряет синтез в разы, без GPU
считает на CPU — медленнее, но работает.

## Установка (однократно, нужен интернет)

```bash
bash tts/setup.sh
```

Создаёт `tts/.venv` и ставит PyTorch (~3 ГБ на диск, качается разово).
При первом синтезе Silero скачает свои веса (~60 МБ) в `~/.cache/torch`.
Повторный запуск setup безвреден.

## Выбор голоса

Послушать все 5 голосов (запишутся в `tts/out/demo/`):

```bash
tts/.venv/bin/python tts/book2audio.py --demo
```

- aidar, eugene — мужские
- baya, kseniya, xenia — женские

## Запуск

```bash
tts/.venv/bin/python tts/book2audio.py книга.fb2
tts/.venv/bin/python tts/book2audio.py книга.epub --voice kseniya
tts/.venv/bin/python tts/book2audio.py роман.txt --rate 15 --out роман
```

Результат: `tts/out/<книга>/01 - <глава>.mp3, 02 - …` (моно 64 кбит/с,
id3-теги автор/название). Готовые главы при повторном запуске
пропускаются — можно останавливать (Ctrl-C) и продолжать;
`--force` — перегенерировать всё.

Шпаргалка со всеми примерами:

```bash
tts/.venv/bin/python tts/book2audio.py help
```

(показывается и при запуске без аргументов).

## Флаги

| Флаг | Что делает |
|---|---|
| `--voice ИМЯ` | голос: aidar, baya, kseniya, xenia, eugene |
| `--rate N` | темп в %: 20 — быстрее, −20 — медленнее (от −50 до 50) |
| `--out ПАПКА` | куда класть главы (относительная — внутри `tts/out/`) |
| `--force` | перегенерировать и уже готовые главы |
| `--device cpu` | считать на CPU (по умолчанию — GPU, если есть) |
| `--demo` | демо-абзац каждым голосом → `tts/out/demo/` |
| `--list-voices` | просто список голосов |

## Откуда берутся главы

- **fb2** — разделы `<section>`, название главы из её `<title>`;
  автор и название книги — из `<title-info>`; стихи читаются построчно;
- **epub** — файлы в порядке spine; заголовок — первый `<h1>…<h6>`
  файла; слишком короткие куски (обложки, оглавления) приклеиваются
  к предыдущей главе;
- **txt** — строки вида «Глава …», «Часть …», «Пролог», «Эпилог»
  (латиница тоже); если таких нет — книга режется на части примерно
  по 10 минут звучания, по границам абзацев.

## Частые проблемы

- **Первый запуск долго думает** — качаются веса Silero (~60 МБ),
  дальше быстро.
- **Считает на CPU, хотя есть NVIDIA** — PyTorch встал без CUDA.
  Проверка: `tts/.venv/bin/python -c "import torch; print(torch.cuda.is_available())"`.
  Лечение: `rm -rf tts/.venv && bash tts/setup.sh`.
- **fb2 не читается** — файл с кривой разметкой; откройте в читалке
  и пересохраните или дайте txt/epub.
- **В txt не те главы** — эвристика ищет строки «Глава/Часть/…»;
  если их нет, режем по длительности (см. выше).
