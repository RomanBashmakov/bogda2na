# service/ — онлайн-конструктор «картина из бисера по вашей картинке»

Отдельное Flask-приложение бренда 2N: клиент загружает картинку,
выбирает формат (A6/A5/A4) и уровень цвета (Простая 3 / Детальная 7 /
Максимум 10), двигает рамку-кроп на фото, правит «пиксели» в
мини-редакторе — и получает рендер «бисер в раме» (с водяным знаком)
и цену. Кнопка «Заказать» копит заказы в `service/orders/`.

Производственная схема (кружки с номерами коробочек) — внутренний
инструмент мастера и клиенту **не показывается**: она выпускается из
сохранённого заказа скриптом `scheme_from_order.py`.

## Запуск (из корня проекта)

```bash
python3 service/app.py            # http://127.0.0.1:8100
python3 service/app.py --no-browser --host 0.0.0.0 --port 8080
```

Зависимости: flask + Pillow (уже в requirements.txt корня).

## Поток и API

| Что | Эндпоинт | Отдаёт клиенту |
|---|---|---|
| Настройки | `GET /api/config` | форматы, уровни, лимит загрузки |
| Сборка | `POST /api/digitize` | пиксельная сетка (цвета + клетки) |
| Рендер+цена | `POST /api/render` | PNG с водяным знаком + цена числом |
| Заказ | `POST /api/order` | номер заказа |

В браузер **не** отдаются: таблица цен (только итоговое число),
рендер без водяного знака, производственная схема.

## config.json

- `formats` — сетки бисерин (шаг 4.5 мм): A6 23×33, A5 33×47, A4 46×66
  (альбомная ориентация — перестановкой);
- `levels` — Простая 3 / Детальная 7 / Максимум 10 цветов;
- `prices` — **таблица 3×3, правьте под себя** (текущие числа —
  заглушки): `prices[формат][уровень]`;
- `watermark` — текст и прозрачность водяного знака на рендере;
- `pitch_mm`, `dither`, `upload_max_mb` — физика и лимиты.

## Заказы

`service/orders/NNN/`: `order.json` (параметры, контакты, сетка),
`source.*` — исходная загрузка, `pixels.png` — что правил клиент,
`render.png` — водяной рендер, `схема/` — появляется после запуска:

```bash
python3 service/scheme_from_order.py 0001    # один заказ
python3 service/scheme_from_order.py --all   # все
```

Уведомления о заказах (Telegram/email) — не сделано, следующий шаг.

## Выкладка в интернет

Timeweb-хостинг 2n-beads.art — только PHP, Flask там не живёт.
Варианты: VPS + поддомен (app.2n-beads.art) со ссылкой/iframe со
страницы WordPress, либо (позже) порт логики на PHP. Перед выкладкой:
`--host 0.0.0.0` за реверс-прокси с TLS, HTTPS-only куки, rate-limit
на `/api/*`, регулярная чистка `uploads/` и `renders/`.

## Чистка

файлы. `service/orders/` — не удалять, это история продаж.
