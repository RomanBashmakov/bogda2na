# picher — рисовалка схем плетения

Редактор схем для бисероплетения: не генерирует схему из надписи или
картинки, а позволяет «натыкать» её мышью самому. Клетка = одна бисерина,
номер в клетке = номер коробочки с бисером этого цвета (№0 — фон).

## Как открыть

```bash
python3 web/app.py        # http://127.0.0.1:8000
```

На странице веб-интерфейса — вкладка «Рисовать схему» → кнопка
«Открыть редактор» (или сразу `http://127.0.0.1:8000/picher`).

## Что умеет

- **Новая схема** — любой размер (колонки × ряды) или старт из пресета
  `patterns/config.json` (берутся размеры и палитра). Размер начатой
  схемы можно менять: лишнее обрезается, новое — пустое; угол-привязка
  (ЛВ/ПВ/ЛН/ПН) задаёт, что остаётся на месте. «Обрезать до выделения» —
  поле становится ровно выделенному прямоугольнику.
- **Инструменты** — кисть (тянется мышью), ластик (стирает в «пусто»),
  заливка области, линия, прямоугольник, овал (контур или заливка —
  галочка «заливать»), выделение.
- **Палитра-коробочки** — цвета из пресета можно править: hex, имя,
  добавить новый, удалить (№0 — фон, его удалить нельзя; при удалении
  цвета его клетки становятся пустыми, номера сдвигаются). Рядом с каждым
  цветом — сколько бисерин нарисовано.
- **Симметрия** — зеркала ←→ и/или ↑↓ относительно центра сетки: каждый
  штрих дублируется в отражённые клетки.
- **Раппорт** — выдели прямоугольник → «Повторить до конца»: блок
  копируется вправо до конца схемы, последний неполный повтор обрезается.
- **Рамка** — инструмент «Рамка» (размер в клетках задаётся полями
  «Рамка, колонок/рядов» в секции «Выделение», помнится): прямоугольник
  фиксированного размера ходит за мышью по полю и всегда целиком внутри
  него. Под схемой — окно предпросмотра: содержимое рамки/выделения
  всегда влезает целиком (клетка подбирается автоматически, до 24 px,
  высота окна плавает в пределах 100–260 px под пропорции). Клик —
  рамка становится выделением (раппорт, обрезка, Ctrl+C/X), режим
  выключается; Esc — просто выйти. Рамку больше поля включить нельзя
  (предупреждение).
- **Копирование/вставка** — Ctrl+C копирует выделение (без выделения —
  всё поле), Ctrl+X вырезает, Ctrl+V — блок-«призрак» ходит за мышью,
  клик ставит его (многократно, выступ за поле обрезается), Esc — отмена;
  R / H / V — поворот на 90° и отражения ←→ / ↑↓ (те же действия —
  кнопками). Блок пишется и в системный буфер текстом-JSON → перенос
  между вкладками и сессиями («Вставить из буфера…»). Цвета при вставке
  матчатся по hex, отсутствующие добавляются в палитру.
- **«Пустое → фон №0»** — одной кнопкой закрасить всё незакрашенное
  цветом фона.
- Прочее: отмена/повтор (до 50 шагов, Ctrl+Z / Ctrl+Shift+Z), Esc — снять
  выделение, зум — панелькой над схемой (− / значение / + / по ширине),
  номера коробочек в клетках вкл/выкл, линейки каждые 10 колонок.

## Сохранение

- **На сервере** — «Сохранить на сервер» (Ctrl+S) кладёт файл
  `picher/schemes/<имя>.json`; список ниже с открытием и удалением
  (папка в git не попадает).
- **Файлом** — «Экспорт JSON» скачивает ту же схему файлом,
  «Импорт JSON» открывает такой файл обратно.

Формат файла: `{version, cols, rows, colors: [{name, hex}], cells: [...]}`,
`cells` — плоский массив длиной cols×rows: номер цвета или `-1` (пусто),
порядок — по рядам сверху вниз.

## Чего пока нет

Экспорта в печатную A4-схему (кружки-бисерины, легенда, одноцветные
файлы — как у генераторов) — отдельный следующий шаг.
