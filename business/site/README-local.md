# site/README-local.md — локальная копия сайта 2n-beads.art

Файлы сайта (WordPress + WooCommerce, тема bono) лежат в
`site/public_html/` — это выгрузка с хостинга Timeweb. Контент
(товары, страницы, настройки) живёт в MySQL, поэтому для «настоящей»
копии нужен ещё дамп базы.

## 1. Дамп базы (один раз, руками — 2 минуты)

Панель Timeweb (hosting.timeweb.ru) → раздел «Базы данных MySQL» →
база `cq372193_pdry5` → «Экспорт» / phpMyAdmin → формат **SQL** →
скачанный файл положить в `site/db_dumps/01-dump.sql`.
Без дампа контент сайта будет пустым (тема и плагины останутся).

## 2. Запуск

```bash
cd site
docker compose up -d          # поднимает wordpress + mariadb + pma
# сайт:    http://localhost:8080
# phpMyAdmin: http://localhost:8081
```

При первом старте дампы из `site/db_dumps/` импортируются в базу
автоматически. Если база уже инициализирована, дампы игнорируются —
для переимпорта: `docker compose down` и удалить `site/mysql/`.

## 3. Ссылки на localhost

После импорта в базе остаются адреса `https://2n-beads.art`. Один
раз выполнить:

```bash
docker compose run --rm wpcli
```

(заменяет URL на `http://localhost:8080` по всем таблицам и
закрывает сайт от индексации — локальная копия не должна светиться
в поиске).

## 4. Что где

| Путь | Что |
|---|---|
| `site/public_html/` | файлы сайта (в git не попадают) |
| `site/db_dumps/` | SQL-дампы для автоимпорта (в git не попадают) |
| `site/mysql/` | данные MariaDB (в git не попадают) |
| `site/.env` | имя/пользователь/пароль БД + root-пароль (создаётся из `wp-config.php`, в git не попадает) |
| `site/docker-compose.yml` | контейнеры (в git попадает) |

`wp-config.php` пропатчен getenv-фоллбеками: без переменных окружения
ведёт себя как раньше (боевые значения), локально константы
перекрываются контейнером. Загружать патченный файл обратно на
хостинг безопасно.

## 5. Осторожно

- Ничего из `public_html/` не заливать обратно без нужды.
- `docker compose down -v` не используется (томов нет, данные в
  `site/mysql/`).
- Дамп базы содержит заказы и клиентов — не выкладывать в публичный
  доступ (папка уже в .gitignore).
