Сервис (service/, Flask + Pillow, отдельное приложение бренда 2N):

- поток клиента одной страницей: загрузка картинки (drag&drop или
  выбор, png/jpg/webp/gif/bmp, до 20 МБ) → формат A6/A5/A4 +
  книжная/альбомная (шаг 4.5 мм: 23×33 / 33×47 / 46×66 бисерин) →
  уровень цвета Простая (3) / Детальная (7) / Максимум (10) →
  кроп-рамка на фото залочена под пропорции формата (двигается,
  тянется за уголок, затемнение вне рамки) → «Собрать картину»;
- POST /api/digitize: сервер подгоняет кроп к точной пропорции
  сетки (всегда внутри рамки пользователя) и постеризует картинку
  (picher/digitize.py, BOX-усреднение, без дизеринга); клиенту
  отдаётся пиксельная сетка (цвета + клетки);
- мини-редактор в браузере: палитра-свотчи, кисть / «вернуть
  цвет», отмена/повтор (Ctrl+Z / Ctrl+Y, до 100 штрихов), «сбросить
  правки», зум (− / + / по ширине), счётчик правок;
- POST /api/render: цена из таблицы 3×3 (service/config.json;
  числа-заглушки — вводит владелец) и рендер «бисер в раме»
  (service/beads.py: кружки с ободком, бликом и разбросом тона,
  паспарту, деревянная рама с золотой линией) — ТОЛЬКО с
  диагональным водяным знаком «2N · 2n-beads.art» (текст и
  прозрачность — в конфиге); таблица цен и алгоритмы в браузер не
  отдаются, клиент получает только итоговое число;
- POST /api/order: заказ копится в service/orders/NNN/ (order.json,
  исходник, pixels.png, водяной render.png); уведомления
  (Telegram/email) — следующий шаг, не в этой правке;
- service/scheme_from_order.py: заказ → печатная производственная
  схема (кружки, номера коробочек, A4, picher/render.py) —
  внутренний инструмент мастера, клиенту не показывается;
- service/README.md: запуск (python3 service/app.py, порт 8100),
  правка цен, структура заказов, выкладка (хостинг 2n-beads.art —
  PHP-only, нужен VPS/поддомен).

Локальный WordPress (site/):

- site/docker-compose.yml: wordpress + mariadb + phpMyAdmin + wpcli;
  SQL-дампы из site/db_dumps/ импортируются при первом старте,
  разовый `docker compose run --rm wpcli` переносит URL
  2n-beads.art → localhost:8080 и закрывает копию от индексации;
- site/public_html/wp-config.php: getenv-фоллбеки констант DB_*
  (без переменных окружения — прежние боевые значения, загрузка
  файла обратно на хостинг безопасна); site/.env создан из
  wp-config.php + случайный root-пароль (в git не попадает);
- site/README-local.md: где взять дамп базы (панель Timeweb →
  «Базы данных MySQL» → Экспорт), запуск, фиксы URL, карта папок;
- чистка: удалён случайный дубль web/public_html (392 МБ); .gitignore
  дополнен (site/public_html, site/.env, site/db_dumps, site/mysql,
  service/uploads|renders|orders).
