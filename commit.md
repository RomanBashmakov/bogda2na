feat(веб): локальный интерфейс менеджера генераторов схем — web/app.py (Flask)

Запуск генераторов из браузера вместо команд в терминале:

- web/app.py — Flask-приложение, только 127.0.0.1 (порт 8000,
  флаги --port / --no-browser, браузер открывается сам):
  * формы запуска patterns/glitch.py, belt_rus_generator/belt_rus.py
    (кнопка — параметров нет), img_generator/img_belt.py; argv
    собирается списком без shell, интерпретатор — .venv при наличии,
    иначе текущий (логика как в setup.sh); --out из формы — только
    имя файла, всегда внутри out/ своего генератора;
  * загрузка картинок в web/uploads/ (png/jpg/jpeg/gif/bmp/webp),
    выбор ранее загруженной, удаление;
  * список готовых схем из всех трёх out/: одна строка на генерацию
    (основной html + папка <имя>_colsN_colorsM/), просмотр новой
    вкладкой /view/<gen>/<файл>, удаление файла вместе с папкой
    одноцветных схем (с подтверждением), раскрытие списка
    одноцветных файлов по клику;
  * stdout/stderr скрипта в ответе, ссылки на созданные файлы,
    понятные 400-е на плохие параметры и попытки обхода путей;
- web/templates/index.html, web/static/app.js, web/static/style.css —
  страница на русском: 3 вкладки-формы, все параметры генераторов
  (редкие — в сворачиваемом «Дополнительно»), пресеты glitch
  из patterns/config.json;
- requirements.txt: + Flask>=2.0 (при системном Python без pip:
  sudo apt install python3-flask); .gitignore: + web/uploads/;
- README.md: раздел «Веб-интерфейс» — запуск и печать.

Проверено: GET / и статика 200; /api/state — пресеты и схемы
