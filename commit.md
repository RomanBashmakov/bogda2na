d3Sc: переключатель вида 2D-схемы, защита от кэша, меню загрузки, запуск

- 2D-развёртка: radio «кружки | стежки»; вид «стежки» — вертикальные
  капсулы бисерин (мозаичный сдвиг нечётных рядов на полбисерины),
  шаг по горизонтали = (h+h)/2 бок-к-боку, по вертикали — от ширины
  бисерины w; вид «кружки» прежний
- index.html: style.css и app.js подключаются с версией ?v=Date.now()
  (document.write при парсинге) — кэш браузера больше не показывает
  старую версию после правок
- меню «Загрузить» (default/): href из листинга http.server уже
  URL-закодирован — раньше кодировался повторно, файлы с пробелами
  в имени давали 404 и из-за общего try/catch стирали всё меню; теперь
  value — href как есть, подпись — decodeURIComponent, автозагрузка
  вынесена из try и при ошибке перебирает остальные схемы; при открытии
  file:// меню показывает «— запустите ./run.sh (нужен http) —»
- новый run.sh: поднимает python3 -m http.server :8100 (если порт
  свободен) и открывает страницу по http — только так работает список
  схем (на file:// браузер запрещает чтение папки); README «Запуск»
  переписан соответственно
- проверено headless Chrome: file:// и http://127.0.0.1:8100 (схемы
  base_15.json, base_15 copy.json с пробелом, base_15_KY.json),
  переключение вида, автозагрузка и ручное переключение схем, обе ветки
  run.sh; JS-ошибок нет
