feat(img_generator): шпаргалка help в img_belt.py — по образцу glitch.py

Команда «python3 img_generator/img_belt.py help» (и запуск без
аргументов) печатает шпаргалку вместо ошибки «Картинка не найдена:
help»: описание генератора, примеры запуска с реальной koi.png,
принцип работы (постеризация в N цветов → клетки-бисерины → блоки
под A4 с глобальной нумерацией), частые флаги (-n, --cols, --dither,
--no-numbers, --mirror, --out), расположение файлов и отсылка к
полному --help. Докстринг скрипта дополнен упоминанием шпаргалки.

Ранее в этой же папке: img_belt.py — генератор схем из произвольной
картинки (Pillow): постеризация медианным срезом в 2-30 цветов без
дизеринга (--dither — Флойд—Стейнберг), ряды из пропорций при длине
--cols, блочная разбивка большого полотна под листы A4 (склейка
по глобальным номерам рядов/колонок), выход в том же виде, что
glitch.py / belt_rus.py. Пример: img_generator/out/koi.html —
сетка 200×200, 8 цветов, 24 блока, 22 страницы, 40000 бисерин.

Проверено: help и запуск без аргументов → одинаковая шпаргалка,
exit 0; «Картинка не найдена» больше не появляется; argparse --help
и обычная генерация работают.
