feat(генераторы): одноцветные схемы — HTML-файл на каждый цвет

Рядом с основным HTML каждый скрипт (glitch.py, belt_rus.py,
img_belt.py) теперь кладёт папку <имя>_cols<N>_colors<M>/ (N — колонки
сетки, M — число используемых цветов), а в ней — файл <имя>_<№>.html
на каждый цвет (№ = номер коробочки, включая фон):

- кружки этого цвета залиты, без цифры — вместо неё перекрестие-метка
  центра (новая функция glitch.center_mark_svg);
- остальные кружки прозрачные: fill="none" + обводка 0.12 мм, без цифр;
- шапка, легенда, калибровка, сегменты и нумерация — как в основной
  схеме; в заголовке пометка «одноцветная схема · цвет №N …».

Реализация: параметр only_color в segment_svg / block_svg /
render_document; запись файлов — в main() каждого скрипта; обновлены
докстринги, шпаргалки help и patterns/README.md.

Проверено: glitch «ЭХО» 60×10 → 6 файлов, заливки/контуры/крестики в
каждом сходятся с легендой, цифр в кружках нет; belt_rus → 7 файлов по
2000 кружков; img_belt (fish.jpg, 5 цветов) → 5 файлов; --no-numbers
OK; основные схемы не изменились.
