d3Sc: переключатель вида 2D-схемы «кружки/стежки», защита от кэша, меню загрузки

- 2D-развёртка: radio «кружки | стежки» в панели развёртки; вид «стежки» —
  вертикальные капсулы бисерин (мозаичный сдвиг нечётных рядов на
  полбисерины), шаг по горизонтали = (h+h)/2 бок-к-боку, по вертикали —
  от ширины бисерины w; точки-«грунт» на свободных местах; вид «кружки»
  прежний
- index.html: style.css и app.js подключаются с версией ?v=Date.now()
  (document.write при парсинге) — браузер при каждой перезагрузке берёт
  файлы с диска, кэш больше не показывает старую версию после правок
- меню «Загрузить» (default/): href из листинга http.server уже
  URL-закодирован — раньше кодировался повторно (encodeURIComponent),
  файлы с пробелами в имени давали 404 и из-за общего try/catch
  стирали всё меню; теперь value — href как есть, подпись —
  decodeURIComponent, автозагрузка вынесена из try и при ошибке одной
  схемы перебирает остальные
- проверено headless Chrome: file:// и http.server (default/base_15.json,
  base_15 copy.json с пробелом), переключение вида туда-обратно,
  автозагрузка и ручное переключение схем, JS-ошибок нет
