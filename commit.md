feat(picher): инструмент «Рамка» — фрейм-выделение с живым предпросмотром

- новый инструмент «🔲 Рамка» (кнопка в «Инструментах», курсор-crosshair):
  прямоугольник фиксированного размера ходит за мышью по полю, левый
  верхний угол = клетка под курсором, у края рамка прижимается внутрь —
  всегда целиком в поле;
- размер рамки (колонок × рядов, в клетках) — два поля в секции
  «Выделение»; по умолчанию 10×10, помнится между включениями, правится
  на лету; рамку больше поля включить нельзя (предупреждение), при
  уменьшении поля активный режим тихо выключается;
- клик — рамка становится обычным выделением (работают «Повторить до
  конца», «Обрезать до выделения», Ctrl+C/X), инструмент переключается
  на «Выделение»; Esc — выйти из режима, не снимая выделения;
- окно предпросмотра под канвой, видно всегда: в режиме рамки — её
  содержимое под мышью (мышь вне поля — подсказка «наведи мышь»), вне
  режима — текущее выделение, иначе серое «нет выделения»; подпись
  «рамка/выделение W×H · кол. a–b, ряд c–d»;
- предпросмотр всегда вмещает содержимое целиком: клетка подбирается
  автоматически (1–24 px) по ширине окна и высоте бокса, высота окна
  плавает под пропорции (100–260 px), содержимое по центру; номера
  коробочек — при клетке ≥ 13 px (как в основном поле); пересчёт при
  изменении размера окна браузера;
- статусная строка в режиме: «рамка W×H: двигай мышью, клик — выделить,
  Esc — выход»;
- зум основного поля перенесён из сайдбара на тонкую панель над схемой
  (− / значение px / + / по ширине);
- picher/README.md: пункт «Рамка» в «Что умеет», зум — в «Прочее».
