# Карандаш-раздатчик бисера

Ручное устройство «как карандаш»: внутри бисер одного цвета, наводишь
носом на ячейку матрицы (`3D/STL_3d_matrix`), жмёшь клавишу — в ячейку
падает **ровно одна бисерина**. Затея — убрать самое медленное в
раскладке полотна: ходы между коробочкой с бисером и целевой ячейкой.
Просыпание через сито не годится: 0–3 бисерины в ячейку, потом ручная
корректировка.

## Принцип

1. **Куча → очередь.** Бункер-воронка наверху сужается в канал-магазин
   Ø чуть больше бисерины (две рядом не проходят) — бисер стоит колонной.
2. **Очередь → такт.** Под каналом поперёк оси скользит пластинчатый
   слайдер с окном-карманом глубиной ровно на одну бисерину:
   - покой — окно под каналом, нижняя бисерина колонны стоит в окне
     на дне полости;
   - нажал — окно уехало над выходное отверстие, бисерина провалилась
     в нос и из него в ячейку;
   - отпустил — резинка вернула слайдер, окно снова под каналом,
     колонна досыпала следующую.
   Дно полости глухое везде, кроме выходного отверстия — мимо окна
   бисер не проходит никогда, двух бисерин за такт не бывает.

Нос — поясок Ø2.9: входит в ячейку матрицы 3.0 и самоцентрируется,
бисерина падает с минимальной высоты и не подскакивает.

## Детали (out/)

| Файл | Что это | Печатать |
|---|---|---|
| `pen_body.stl` | корпус со стволом-бункером, клапаном, кронштейном резинки | как в файле (бункером вниз), без поддержек |
| `pen_slider.stl` | слайдер с окном-карманом и клавишей | как в файле; **2–3 запасных** |
| `pen_cap.stl` | крышка бункера | как в файле |
| `pen_assembly.stl` | полная сборка: корпус + слайдер (покой) + крышка | **справочный**, не печатать |
| `stand_8.stl` | подставка на 8 карандашей носами вниз | как в файле |
| `fit_test.stl` + `fit_key.stl` | калибровка принтера (см. ниже) | перед карандашом |

Параметры под другой бисер: `--bead-d` / `--bead-h` (дефолт Delica 15/0:
Ø1.73×1.46), `--slots` для подставки, `--clear` — зазор посадки слайдера.

```bash
.venv/bin/python 3D/bead_pen/make_bead_pen.py            # всё
.venv/bin/python 3D/bead_pen/make_bead_pen.py --what pen # только карандаш
```

## Калибровка (один короткий прогон перед печатью карандаша)

`fit_test.stl` + `fit_key.stl`, читаем слева направо:
1. пять каналов Ø1.9–2.3 — куда бисер проходит свободно, но не болтается
   → это Ø магазина; если отличается от дефолтного 2.1 — пересобрать
   с `--bead-d` по факту (диаметр канала = Ø бисерины + 0.37);
2. четыре пояска Ø2.7–3.0 — какой входит в ячейку матрицы без болтанки;
3. четыре паза (зазор 0.15–0.30) + ступенчатый ключ: где ключ ходит
   гладко, без люфта и заклинивания → тот зазор задать в `--clear`.

Отверстия после печати обычно уже номинала: канал магазина и окно
слайдера прогнать сверлом Ø2 мм.

## Сборка

1. Слайдер вставить в полость клапана клавишей наружу (клавиша снаружи
   упирается в кронштейн — слайдер не выпадет; хвост изнутри упирается
   в дальнюю стенку — такт ограничен).
2. Канцелярская резинка: через отверстие в клавише, концами за два
   отверстия кронштейна. Натяжение перещёлкивать за другое отверстие.
3. Засыпать бисер в воронку (ёмкость ~300 бисерин 15/0), надеть крышку.

Если бисер не сыплется в канал — постучать карандашом по столу (свод
над горлом воронки). Если заклинило окно — вынуть слайдер, вытряхнуть,
прогнать сверлом.

## Работа

По одному заряженному карандашу на цвет, стоят в подставке носами вниз
(лунка на торце подставки — под бирку с номером цвета). Навёл — нажал —
перевёл на следующую ячейку. Поясок носа ставится в ячейку и
самоцентрируется, целиться можно «на ощупь».
