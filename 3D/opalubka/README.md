# Опалубка — рамка для сборки бисерного полотна

Полотно собирается прямо в рамке, рамка остаётся оформлением и упаковкой.
Две детали STL, печать плашмя без поддержек в ориентации файла
(низ — дном на стол, верх — пластиной на стол).

## Как устроено

- **Нижняя половина** (`<имя>_bottom.stl`): дно-полочка со сквозным
  окном (`--base-t`, по умолчанию 2 мм — рамка жёсткая). По краю
  полотна — гребёнки-«стенки»: ровные вертикальные столбики от края
  полотна до наружного края низа (глубина ≈ 2 мм), сверху их объединяет
  сплошная **полка** `--shelf-t`. Столбики стоят **в промежутках между
  нитками**, поэтому **окошек ровно по числу ниток** (рядов и прошивок)
  и точно на их центрах: нитка запирается в окошке со всех четырёх
  сторон (столбики + дно + полка) и не соскакивает.
- **Прошивка насквозь**: иголка с ниткой входит снаружи и проходит
  окошко насквозь — за столбиками на высоте окошек ничего нет, отдельные
  прорези и канавки не нужны. Хвосты ниток выходят наружу через те же
  окошки — подрезать/подклеить по вкусу.
- **Верхняя половина** (`<имя>_top.stl`): пластина с пальцем-прижимом
  и наружной **юбкой-ключом** `--wall` (1.2 мм) на всю высоту сборки:
  при закрытии юбка накрывает низ снаружи до самого стола — верх
  «поглощает» нижнюю половинку, стык центрирует детали и прячет шов.
  Зазор прижима = толщине полотна: палец давит на крайние бисерины,
  лежащие на полочке. Посадка плотная, при желании — клей.
- Окно сквозное в обеих половинках: полотно видно с двух сторон и
  «висит в воздухе».

## Порядок сборки полотна

1. Нижняя половина лежит на столе (стол закрывает окно, бисер середины
   стоит на столе через окно).
2. Горизонтальный ряд: иголка снаружи проходит окошко левой гребёнки
   (окошек = рядов, шаг = высота бисерины), на нитку нанизывается бисер
   ряда, иголка выходит через окошко правой гребёнки — нитка заперта
   в окошках. Повторить ряд за рядом, держа натяг.
3. Прошить полотно вертикально пустой нитью между бисеринами: её нити
   проходят через окошки верхней и нижней гребёнок (окошек = числу
   прошивок, шаг = ширине бисерины).
4. Хвосты, вышедшие наружу через окошки, подклеить/подрезать, надеть
   верхнюю половинку: палец входит в карман, юбка-ключ накрывает низ
   снаружи. Прижать.

## Параметры (CLI и вкладка «Опалубка» веб-панели)

| Параметр | По умолчанию | Что это |
|---|---|---|
| `--cols` | 26 | бисерин в ряду (ширина полотна) |
| `--rows` | 52 | рядов (высота полотна) |
| `--bead-w` | 1.4615 | ширина бисерины, мм = шаг верх/низ гребёнок |
| `--bead-h` | 1.7308 | высота бисерины, мм = шаг боковых гребёнок |
| `--fabric-t` | 1.73 | толщина полотна = зазор прижима, мм |
| `--tooth-h` | 1.3 | высота столбиков вместе с полкой (меньше толщины полотна) |
| `--shelf-t` | 0.5 | полка над столбиками: замыкает окошко сверху, мм (окошко = tooth_h − shelf_t в высоту) |
| `--ledge` | 1.0 | выступ полочки ПОД полотно, мм (окно = полотно − 2×выступ) |
| `--border` | 4.2 | толщина видимой рамки от края окна, мм (включает юбку-ключ верха) |
| `--slot` | 0.8 | ширина окошка между столбиками, мм (столбик = шаг − окошко) |
| `--clearance` | 0.15 | зазор посадки пальца и юбки, мм |
| `--base-t` | 2.0 | дно-полочка нижней половинки, мм |
| `--top-t` | 1.0 | пластина верхней половинки, мм |
| `--finger` | 0.7 | высота пальца-прижима, мм |
| `--wall` | 1.2 | толщина юбки-ключа верхней половинки, мм |
| `--name` | opalubka | имя файлов |

Дефолты = полотно 26×52 бисерин → 38×90 мм (Delica-подобный бисер),
окно 36×88, габарит сборки 44.4×96.4 (низ 41.7×93.4 прячется под юбкой),
глубина сборки ≈5.4 мм.

## Запуск

Из папки со скриптом или из веб-панели (вкладка «Опалубка»):

```bash
python3 make_opalubka.py                      # дефолты
python3 make_opalubka.py --cols 20 --rows 40 --border 5 --name ramka
```

Результат: `out/<имя>_bottom.stl`, `out/<имя>_top.stl` — бинарный STL,
замкнутый (рёбер без пары нет). Скрипт без зависимостей, чистая
стандартная библиотека.

## Замечания

- Размер полотна в мм = `cols × bead-w` на `rows × bead-h`; шаги гребёнок
  измерьте по своему бисеру (у плотных цилиндрических бисерин ширина чуть
  меньше высоты).
- Окошек ровно по числу ниток и точно на их центрах: столбики стоят
  В ПРОМЕЖУТКАХ между нитками, поэтому их на 1 больше (боковые =
  рядов + 1, верх/низ = бисерин в ряду + 1). Иголка с ниткой проходит
  окошко насквозь — за столбиками ничего нет.
- Ключ-соединение: юбка верхней половинки (толщиной `--wall`) накрывает
  низ снаружи до стола с зазором `--clearance`; низ при этом
  меньше сборки на 2×(юбка + зазор). Половинки центрируются сами.
- «Толщина рамки» — от края окна; на полочку + гребёнку (0.8 мм
  минимум) + юбку с зазором должно хватить, иначе скрипт откажется
  (дефолт 4.2 = 1.0 + 1.85 + 0.15 + 1.2).
- Хвосты ниток выходят наружу через окошки — подрезать или подклеить
  по вкусу; при закрытии юбка верха накрывает их снаружи.
