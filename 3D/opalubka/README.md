# Опалубка — рамка для сборки бисерного полотна

Полотно собирается прямо в рамке, рамка остаётся оформлением и упаковкой.
Две детали STL, печать плашмя без поддержек в ориентации файла
(низ — дном на стол, верх — пластиной на стол).

## Как устроено

- **Нижняя половина** (`<имя>_bottom.stl`): пластина со сквозным окном,
  по периметру окна карман-«ступенька» с полочкой. Полоска полочки шириной
  «выступ полочки» — гладкая (на неё ложатся крайние бисерины), по её краю —
  зубья-колышки точно на центрах ниток, наклонённые от полотна. За
  колышками до стенки кармана — канавка, в которую надевается нить:
  наклонённая вершина нависает над канавкой крючком и держит нитку.
- **Прорези для хвостов**: в каждой из 4 стенок низа по 2 сквозные
  прорези шириной = зазору между зубьями, ровно на первой и последней
  нити этой стороны (см. эскизы `прорези`/`прорезь` в корне проекта).
  Нить заводится снаружи через прорезь и выходит через прорезь;
  вдоль внешней стенки по всему периметру — углубление `--tail-groove`
  (0.2 мм) с уступом дна: туда ложатся хвосты, капается супер-клей
  (якорь для натяга в начале плетения). Юбка верха закрывает всё
  снаружи, не касаясь хвостов: углубление + зазор посадки ≈ 0.35 мм.
- **Верхняя половина** (`<имя>_top.stl`): пластина с пальцем-прижимом
  («негатив» кармана) и наружной **юбкой-ключом** на всю высоту сборки:
  при закрытии юбка накрывает низ снаружи до самого стола — верх
  «поглощает» нижнюю половинку, стык центрирует детали и прячет шов.
  Зазор прижима = толщине полотна: палец давит на крайние бисерины,
  лежащие на полочке; зубья ниже прижимной плоскости, хвосты ниток
  остаются в канавках. Посадка плотная, при желании — клей.
- Окно сквозное в обеих половинках: полотно видно с двух сторон и
  «висит в воздухе».

## Порядок сборки полотна

1. Нижняя половина лежит на столе (стол закрывает окно, бисер середины
   стоит на столе через окно).
2. Нанизать бисер ряда на нить, надеть нить на колышки левой и правой
   гребёнок (шаг = высота бисерины). Начало нити заводится снаружи
   через прорезь (на первой/последней нити), хвост ложится в углубление
   вдоль внешней стенки — капля суперклея на хвост держит натяг.
   Повторить ряд за рядом; конец последней нити — через прорезь туда же.
3. Прошить полотно вертикально пустой нитью между бисеринами; её нити
   надеваются на колышки верхней и нижней гребёнок (шаг = ширине
   бисерины, включая 2 краевые — чтобы полотно не расползалось);
   концы — так же через прорези в углубление.
4. Капнуть клей на хвосты в углублении, надеть верхнюю половинку:
   палец входит в карман, юбка-ключ накрывает низ снаружи (хвосты
   прячутся под ней). Прижать.

## Параметры (CLI и вкладка «Опалубка» веб-панели)

| Параметр | По умолчанию | Что это |
|---|---|---|
| `--cols` | 26 | бисерин в ряду (ширина полотна) |
| `--rows` | 52 | рядов (высота полотна) |
| `--bead-w` | 1.4615 | ширина бисерины, мм = шаг верх/низ гребёнок |
| `--bead-h` | 1.7308 | высота бисерины, мм = шаг боковых гребёнок |
| `--fabric-t` | 1.73 | толщина полотна = зазор прижима, мм |
| `--tooth-h` | 1.0 | высота зубчиков (меньше толщины полотна) |
| `--tooth-lean` | 0.25 | наклон зубьев ОТ полотна: сдвиг вершины, мм (0 — прямые); вершина нависает над канавкой и держит нитку |
| `--ledge` | 1.0 | выступ полочки ПОД полотно, мм (окно = полотно − 2×выступ) |
| `--border` | 3.8 | толщина видимой рамки от края окна, мм (включает юбку-ключ верха) |
| `--slot` | 0.6 | зазор между зубьями, мм (зуб = шаг − зазор) |
| `--channel` | 0.6 | канавка между зубьями и рамкой, куда надевается нить, мм |
| `--clearance` | 0.15 | зазор посадки пальца и окна, мм |
| `--base-t` | 0.7 | дно под полочкой, мм |
| `--top-t` | 1.0 | пластина верхней половинки, мм |
| `--finger` | 0.7 | высота пальца-прижима, мм |
| `--wall` | 0.6 | толщина наружной стенки низа и юбки-ключа верха, мм |
| `--tail-groove` | 0.2 | углубление вдоль внешней стенки под хвосты ниток (суперклей), мм |
| `--name` | opalubka | имя файлов |

Дефолты = полотно 26×52 бисерин → 38×90 мм (Delica-подобный бисер),
окно 36×88, габарит сборки 43.6×95.6 (низ 42.1×94.1 прячется под юбкой),
глубина сборки ≈4.1 мм.

## Запуск

Из папки со скриптом или из веб-панели (вкладка «Опалубка»):

```bash
python3 make_opalubka.py                      # дефолты
python3 make_opalubka.py --cols 20 --rows 40 --border 4 --name ramka
```

Результат: `out/<имя>_bottom.stl`, `out/<имя>_top.stl` — бинарный STL,
замкнутый (рёбер без пары нет). Скрипт без зависимостей, чистая
стандартная библиотека.

## Замечания

- Размер полотна в мм = `cols × bead-w` на `rows × bead-h`; шаги гребёнок
  измерьте по своему бисеру (у плотных цилиндрических бисерин ширина чуть
  меньше высоты).
- Нитка надевается на колышек снаружи: наклонённая вершина нависает над
  канавкой, нитка проходит под ней в канавку и держится. Наклон 0.25 мм
  при высоте зуба 1.0 — это 14° от вертикали, печатается без поддержек;
  ограничение — не круче 45° и меньше канавки (иначе нитка не пролезет).
- Колышков боковых гребёнок = числу рядов, верх/низ = бисерин + 1
  (крайние стоят на краю полотна и держат его от расползания).
- Ключ-соединение: юбка верхней половинки (толщиной `--wall`) накрывает
  наружную стенку низа до стола с зазором `--clearance`; низ при этом
  меньше сборки на 2×(стенка + зазор). Половинки центрируются сами.
- «Толщина рамки» — от края окна; на полочку + зуб (0.5 мм минимум) +
  канавку + стенку низа + зазор + юбку должно хватить, иначе скрипт
  откажется (дефолт 3.8 = 1.0 + 0.85 + 0.6 + 0.6 + 0.15 + 0.6).
- Хвосты ниток: начало и конец каждой нити выводятся через прорези
  (по 2 на стенку, ровно на первой/последней нити) и ложатся в
  углубление `--tail-groove` вдоль внешней стенки; суперклей капается
  прямо туда до закрытия. Нить до ~0.35 мм влезает (углубление 0.2 +
  зазор посадки 0.15), юбка верха проходит поверх не касаясь.
